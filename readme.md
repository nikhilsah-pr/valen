💖 Fun Valentine / Prank Website

A small fun web project built with HTML, CSS, and JavaScript where:

The user is asked a cute question

The “No” button runs away from the cursor 😄

Clicking “Yes” triggers confetti + surprise GIF 🎉

Includes share button, custom font, and easy theme editing

Perfect for learning DOM events, UI interactions, and having some fun.

🚀 Features

😏 Moving “No” button (can’t escape saying Yes)

🎉 Confetti animation on Yes

💌 Surprise GIF reveal

📤 Share button (mobile share / desktop copy link)

🎨 Custom theme colors

✍️ Google Fonts support

📱 Responsive & lightweight

❤️ Optional floating hearts & background music
🛠️ Tech Stack

HTML

CSS

JavaScript

Canvas Confetti

Google Fonts

No frameworks. No build tools. Just pure frontend fun.
